# Marriage Prayers

A static copy of the [marriageprayers.today](https://marriageprayers.today/) home page, served with GitHub Pages.

The one change from the original is a **Prayer of the Day** section — "Dwelling Faithfully Together" from April 8, 2026 — placed just before "A Note About Marriage Prayers".

- `index.html` is the home page; the theme's styles, scripts, fonts and images are copied into `wp-content/` and `wp-includes/` so the page doesn't load them from the original site.
- Links to individual prayers, the archive ("Older Entries") and the other menu pages still go to marriageprayers.today.
- The original site's Google Analytics snippet is removed.

All prayers and content are by Darlene and Michael Schacht, [Time-Warp Wife Ministries](https://timewarpwife.com).
